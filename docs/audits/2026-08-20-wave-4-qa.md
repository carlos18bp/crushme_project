## Behavior Added

- Authentication lifecycle tests cover registration delivery rollback, email
  verification, verified-email protection, refresh replay, server-side logout,
  throttling, password recovery, and protected-route redirects.
- Cart, catalog, checkout, payment-failure, wishlist, admin, discount,
  WooCommerce boundary, currency, and E2E seed behavior now have targeted
  regression evidence.
- E2E selectors were added only where role/name selectors were insufficient.
- The WooCommerce client cannot make remote requests when test integration
  credentials are empty, and test currency conversion uses a fixed rate.
- The temporary forced-COP implementation was replaced with persisted
  preference plus backend geolocation, while the shared HTTP client keeps the
  current `X-Currency` contract.

then P2 negative outcomes; no gap should be hidden with an exemption merely to
